# 1. 项目速览

## 一句话概括

**PROMESST 2** 是一款俯视 2D 光束解谜游戏:玩家在环形卷绕的瓦片世界上,借助**彩色光束(投影器)**、宝石、反射镜、魔杖与自动游走的机器人(rover)破解谜题。站在某种颜色的光束里,角色就能获得对应的“能力”。

## 世界规模

- 世界是 **24×24×2 的环形网格**:坐标越界自动取模卷绕(`WRAP_X/WRAP_Y`,L723–724),没有边缘;
- 切成 **4×4 个房间,每房间 6×6**(`NUM_X/Y = 4`, `SIZE_X/Y = 6`,L200–203),上下两层共 32 个房间;
- 逻辑与渲染基本只关心玩家所在房间及其一圈邻居;`#` 楼梯在两层间切换。

## 核心循环

1. **移动 / 开门穿墙 / 拾取宝石**(方向键 / WASD + X);
2. **点亮房间**:宝石填满房间全部底座 → 房间“通电” → 投影器亮起射出光束;
3. **获得能力**:站进光束获得该色能力(开门 / 穿墙 / 碎石 / 双步 / 沿光束远行);
4. **用魔杖改光路**:Z 键把照到自己的投影器朝向重定向,打通被堵的路径;
5. **通关**:把 30 颗宝石喂给地图上的 rover 机器人,触发结尾动画(YOU WIN)。
