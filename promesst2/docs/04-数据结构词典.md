# 4. 数据结构词典

## 基础类型与位域

| 结构 | 行号 | 字段与含义 |
|---|---|---|
| `color` | L70 | `uint8 r,g,b,a`,通用 RGBA。 |
| `point` | L533 | `int x,y`,投影器坐标。 |
| `sprite_id` | L137 | `int s,t`,精灵表中 (列,行) 的 16px 格索引。 |
| `obj` | L193 | **位域 8bit**:`type:3, dir:2, color:3`,一个字节描述一个物体。 |

## 大结构

| 结构 | 行号 | 说明 |
|---|---|---|
| `player_state` | L209 | 玩家状态:坐标、朝向、携带宝石数 `num_gems`、`has_wand`、能力占用标志、反射镜数、`num_zaps`(按 Z 次数,通关统计)、`gems_stored`(喂给蜥蜴的宝石)、`seen[2]`(每层已探索房间位图)。 |
| `roomsave_big` | L393 | 撤销单元:进房间前的玩家状态 + 该房间“横/竖两条十字”物体带 + 门位图;链表成 `undo_chain`。 |
| `gamestate` | L579 | 整幅世界快照:tilemap + objmap + player_state,用于 checkpoint 与存档。 |
| `roomsave` | L430 | **仅存于 `#if 0`**:更省的“小撤销”设想,作者注释说恢复逻辑太复杂所以放弃。 |

## 全局状态与静态表

| 符号 | 行号 | 含义 |
|---|---|---|
| `tilemap[2][24][24]` | L205 | 两层 24×24 的**地形**(墙/门/地板/楼梯/箭头/底座…),第一维是层 `z`。 |
| `objmap[2][24][24]` | L206 | 同尺寸**物体**网格,元素为 8bit `obj`(石块/宝石/投影器/魔杖/反射镜/rover)。 |
| `edge[2][24][24]` | L207 | 每格 8bit;声明后全代码未见读写(L2532 注释提到 restore 前要 populate),疑似遗留。 |
| `rawmap[24][2]` | L233 | 两层世界 ASCII 关卡源码(24 行 × 每层 24 字符,房间间用空格分隔)。 |
| `tile_sprite[]` | L142 | 瓦片枚举 → 精灵表坐标。 |
| `obj_sprite[]` / `obj_sprite_hasdir[]` | L173 / L187 | 物体 → 精灵坐标;该物体是否随 `dir`(1)或动画(2)换帧。 |
| `powers[8]` | L75 | 8 种颜色实色,`init_graphics` 从精灵表 (96,112..119) 取样填充。 |
| `lights[]` / `lightdata[]` | L278 / L281 | 18 个 ASCII 字母 ↔ (颜色, 照射方向),解析关卡投影器用。 |
| `has_power[4][4]` | L473 | 每房间是否“通电”:有底座且底座全被宝石占满。 |
| `light_for_dir[24][24][4]` / `any_light_for_dir` | L493 | 光照缓存:某格从哪个方向(0–3)照进什么颜色的光;后者是“有光”布尔。 |
| `state` / `px,py,pz,pdir` | L293 | 玩家状态结构体 + 解耦的实时坐标/朝向。 |
| `room_x,room_y,room_z` | L464 | 玩家当前所在 6×6 房间。 |
| `undo_chain` | L611 | `roomsave_big` 撤销栈(链表,随存档落盘)。 |
| `checkpoint` / `checkpoint_timer` | L739 | 拾到魔杖那一刻的全图快照(“RESTORE FROM WAND GET”数据源)。 |
| `queued_key` | L1054 | 事件层按键翻译成 'w/a/s/d/x/z/c' 排队,逻辑节拍里消费。 |
| 各 `*_timer` | L733 起 | `player/rover/shot/feed/reverse/magic/checkpoint` 倒计时(ms),由 `timestep()` 统一递减。 |
| `choices[]` / `credits[]` | L1340 / L1354 | 菜单文案;滚动 Staff 表(含贡献者名单)。 |
| `loaded_game` | L1407 | 存档读入/写出的 `gamestate` 缓冲。 |
| `font[]` / `fsize[]` | L1685 | 内置字体字符表(42 字符)与字宽表,文本渲染不依赖外部字体。 |
