# 5. 关卡 ASCII 图例

看懂 `rawmap`(L233)的字符才能读懂关卡。原注释图例在 L226–232。

## 字符表

| 字符 | 含义 |
|---|---|
| `|` `.` `#` | 墙 `|`;地板 `.`;`#` = 楼梯(走到上面会 `(pz+1)%2` 切层,L843)。 |
| `=` | 宝石底座(receptacle):全部底座被宝石占满 → 房间通电 → 投影器亮起。 |
| `D` | 门(红光照身时可走门并把它打开成 open_door)。 |
| `>` `^` `<` `v` | 地面箭头:rover 经过时按箭头转向。 |
| `*` | 大石块 boulder(黄光照身时可摧毁)。 |
| `1–9` `0` | 已放在底座里的宝石(数字仅用于关卡标注)。 |
| `@` `%` | 散落裸露的宝石(bare gem),无底座。 |
| `&` | rover —— 自动游走的机器人,初始方向由相邻箭头决定(L377–390)。 |
| `/` | 反射镜(斜放):`dir==0` 光束 90° 转向,`dir==1` 折返(`dir^=1 / ^=3`)。 |
| `-` | 魔杖 wand:拾取后 `has_wand=1` 并生成 checkpoint。 |
| `z` | 标记“巢穴”坐标:解析后在其正下方一行铺 1×3 蛋瓦片(L373–375),结尾动画场景。 |
| `p` | 玩家出生点。 |
| 字母 `r R w P g G H y Y L t T V j o O A a` | 18 种投影器:**字母决定颜色与照射方向**,查 `lights[]/lightdata[]`(L278–288)。 |

## 颜色 → 能力对照

| 颜色 | 能力宏 | 效果 | 投影器字母 |
|---|---|---|---|
| 红 red | `POWER_doors` | 开门 | `r R w P` |
| 绿 green | `POWER_walls` | 穿墙 | `g G H` |
| 黄 yellow | `POWER_destroy` | 碎石 | `y Y L` |
| 橙 orange | `POWER_double` | 双步(2^照入数) | `o O A a` |
| 紫 violet | `POWER_travel` | 沿光束远行 | `t T V j` |

> 宏定义见 L707–712;蓝/青/粉在 `powers` 中有色值但未映射为能力。

## 投影器字母的完整映射(来自 lightdata,L281–288)

```c
// 格式:字母 → (颜色, 方向)   方向 E/N/W/S
红:  r→E  R→N  P→S  w→W
绿:  g→E  G→S  H→W
黄:  y→S  Y→E  L→W
紫:  t→W  T→S  V→N  j→E
橙:  o→E  O→W  A→N  a→S
```

> 注:L226 的速记注释排布是近似示意(如 L 的实际方向为 W 而非 N),以代码 `lightdata` 为准。
