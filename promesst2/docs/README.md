## 这是什么

**PROMESST 2** 是 Sean Barrett(stb 单文件库作者)用**纯 C + 自家 stb 库**写的俯视 2D **光照解谜游戏**:

- 玩家站在彩色光束里即可获得对应能力:红色开门、绿色穿墙、黄色碎石、橙色双步、紫色沿光束远行;
- 把宝石填进底座为房间“供电”,点亮投影器产生光束;用魔杖(Z 键)重定向照到自己的光束;
- 世界为 24×24×2 的环形网格,切成 4×4 个 6×6 房间,共两层 32 个房间;
- 把 30 颗宝石喂给游走的 rover 机器人即可通关(它最终会变成彩虹蜥蜴 NPC)。

代码无外部依赖:图像解码、OpenGL 封装、窗口创建全部通过随附的 stb 单文件库内联编译,只需编译 `main.c` 一个文件。

## 如何本地预览本站点

docsify 通过 HTTP 拉取 Markdown,**直接双击 `docs/index.html`(file://)在大多数浏览器里无法加载内容**,需要起一个静态服务器,任选其一:

```bash
# 方式 A:Python
cd docs
python -m http.server 3000
# 浏览器打开 http://localhost:3000

# 方式 B:Node + docsify-cli(需先 npm i -g docsify-cli)
docsify serve docs
# 浏览器打开 http://localhost:3000

# 方式 C:PowerShell 一行版
# 在项目根目录执行:python -m http.server 3000 后访问 http://localhost:3000/docs/
```

> 在线预览依赖 docsify 的 CDN(jsdelivr),需联网加载 `docsify.min.js` 等脚本。
