# 9. 数据资源与构建

## 一张精灵表撑起全部画面(`sprites.png` = 128×128)

- **瓦片 / 物体**:16px 格,由 `tile_sprite[]`(L142)与 `obj_sprite[]`(L173)索引;物体精灵可随 `dir` 或 3 帧动画换格(`obj_sprite_hasdir`,L187)。
- **房间配色**:第 96–111 行(y)、120–127 列区域存多套房间底色,`get_map_color`(L91)按房间坐标取样 —— 不同房间墙面颜色各异,形成“区域感”。
- **能力色条**:`(y=96, x=112..119)` 的 8 个像素即 `powers[8]` 的 8 种颜色,`init_graphics`(L86)直接 memcpy。
- **内置字体**:第 113 行起两行 8px 小格是 42 字符 ASCII 字体(字符集与字宽表在 L1685–1689),文本全部即时画进四边形。
- **蛋 / 蜥蜴 / 装饰帧**:蛋瓦片 `TILE_egg × 8` 与结尾的大蜥蜴、彩虹变身、对话气泡贴图取自表中不同区域(L2035–2069 直接引用 UV 区块)。

> 素材目录 `data2\` 同时是 **Windows 存档位置**(`data2/save.dat`),游戏必须从含 `data2` 的目录运行。

## 构建 / 运行 / 调试

### 运行成品

把 `promesst2.exe` 与 `data2\` 放在同一目录运行;窗口可自由缩放。存档自动写 `data2\save.dat`。

### 编译(仅供参考,未在本机验证)

整个工程只需编译 `main.c`(其余库以 include 内联),`RELEASE` 已默认定义:

```bash
# Windows(MinGW / MSVC,需 Win32 + OpenGL):
gcc -O2 main.c -o promesst2.exe -lopengl32 -lgdi32 -luser32

# Linux / David Gow 移植(需 SDL2):
gcc -O2 main.c -o promesst2 -lSDL2 -lGL
```

### 调试开关

| 宏 | 效果 |
|---|---|
| `RELEASE`(默认开) | 允许写档 + 启动读档进菜单;关掉则每次新开局且不存档。 |
| `_DEBUG` 或 `CHEAT` | 启用 `g`(30 宝石+魔杖)与 `n`(穿墙)作弊键;主循环不再返回暂停。 |
| `TIME_SCALE` | 全局倍速。 |
