# 8. 常量与配置

## 关键宏与常量

| 宏 / 常量 | 值 | 含义 |
|---|---|---|
| `SCREEN_X/Y` | 1024×768 | 逻辑分辨率(窗口可缩放,等比黑边)。 |
| `MAX_GEMS` | 30 | 通关所需喂给蜥蜴的宝石数。 |
| `NUM_X/Y`、`SIZE_X/Y` | 4、6 | 每层 4×4 房间,每房间 6×6。 |
| `PLAYER_MOVE_TIME` | 80 ms | 玩家每步动画时长(远行同值)。 |
| `ROVER_MOVE_TIME` | 630 ms | rover 每步间隔。 |
| `MAGIC_STEP_TIME` | 60 ms | 房间旋转动画每格时长(系统当前未启用)。 |
| `MAX_LOGO` | 1500 ms | 开场 Logo 停留时间。 |
| `checkpoint_timer` 初值 | 1600 ms | 拾魔杖后 “CHECKPOINT SAVED” 提示时长。 |
| `feed / reverse_timer` | 1200 / 1100 ms | rover 吃宝石后的“说话 / 反转”时长。 |
| `TIME_SCALE` | 1 | 全局时间倍速(调试用)。 |

## 枚举与编译开关

| 枚举 / 开关 | 行号 | 说明 |
|---|---|---|
| `RELEASE` | L5 | 默认定义:启用自动读档/存档与成品菜单流程。 |
| `CHEAT` | L1 | 被注释;打开(连同 `_DEBUG`)启用 g/n 作弊键。 |
| `main_mode` | L59 | `M_logo → M_menu → M_credits / M_game` 状态机。 |
| `DIR_e/n/w/s` | L101 | 方向常量与 `xdir/ydir` 位移表。 |
| `TILE_*` | L112 | 18 种地形瓦片(墙/门/地板/底座/箭头/楼梯/蛋×8…)。 |
| `T_*` | L160 | 8 种物体(空/石块/宝石/投影器/魔杖/反射镜/rover)。 |
| `COLOR_*` | L266 | 红绿蓝橙黄紫青粉 8 色索引。 |

## 颜色与能力对应(速查)

| 颜色索引 | 能力宏(值=颜色) | 效果 |
|---|---|---|
| 红 `COLOR_red` | `POWER_doors` | 开门 |
| 绿 `COLOR_green` | `POWER_walls` | 穿墙 |
| 黄 `COLOR_yellow` | `POWER_destroy` | 碎石 |
| 橙 `COLOR_orange` | `POWER_double` | 双步 |
| 紫 `COLOR_violet` | `POWER_travel` | 沿光束远行 |

能力宏定义见 L707–712:`POWER_doors/ walls/ destroy/ double/ travel` 直接取对应颜色枚举值——`get_abilities()` 按颜色计数(`enabled[颜色]++`),所以“能力”本质就是“你被什么颜色的光照着”。
