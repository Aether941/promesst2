# 2. 文件清单与角色

## 顶层目录

| 文件 / 目录 | 大小 | 角色 |
|---|---|---|
| `promesst2.exe` | 143 KB | Windows 可执行成品(Release)。运行时需同目录 `data2\`。 |
| `promesst2_source_code.zip` | 76 KB | 源码目录的打包备份,内容与源码目录一致。 |
| `readme2.txt` | 235 B | 运行说明:方向键移动;Z / X 为装备解锁的动作;退格撤销;窗口可缩放。 |
| `data2\` | — | 游戏资源(3 张 PNG)+ Windows 存档位置(`save.dat`)。 |
| `promesst2_source_code\` | — | 全部源码。 |
| `PROMESST2-源码导读.html` / `-v2.html` | ~62 KB | 本站点之外的 HTML 版导读(v2 为单栏版,推荐)。 |
| `docs\` | — | 本 docsify 站点。 |

## 资源 `data2\`

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `sprites.png` | 128×128 | 一张精灵表装下全部画面:瓦片、物体、角色、房间配色、能力色、内置字体。 |
| `title.png` | 256×128 | 标题画面。 |
| `sss_logo.png` | 128×64 | 开场 Logo(启动显示约 1.5 秒)。 |

## 源码 `promesst2_source_code\`

| 文件 | 大小 | 角色 |
|---|---|---|
| `main.c` | 69 KB / 2543 行 | **全部游戏代码**:关卡数据 + 逻辑 + 渲染 + 存档。文档主角。 |
| `stb_image.c` | 148 KB | stb 图像解码库,被 main.c 直接 `#include`(L38)。 |
| `stb_gl.h` | 38 KB | stb OpenGL 助手:纹理上传 / 绘制封装。 |
| `stb_wingraph.h` | 25 KB | stb Win32 窗口封装(`stbwingraph_*`),`_WIN32` 分支。 |
| `stb_sdl2graph.h` | 19 KB | stb SDL2 窗口封装 —— David Gow 的 Linux 移植(credits 有署名)。 |

## 编译关系

```c
// main.c 顶部把第三方库内联进来,因此只需编译 main.c 一个文件:
#include "stb_image.c"   // L38
#include "stb_gl.h"      // L39
// 窗口层按平台二选一(L22–32):
#ifdef _WIN32
  #include "stb_wingraph.h"
#else
  #include "stb_sdl2graph.h"
#endif
```
